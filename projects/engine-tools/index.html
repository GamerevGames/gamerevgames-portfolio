Overview

Engine Tools is a set of custom Unity Editor tools built to speed up setup and iteration. I designed and built these tools to remove tedious and repetitive steps from my own workflow.

  • Dynamic Patrol System: create and edit AI patrol routes directly from the inspector.
  • Serialized Config Editor Window: edit an agent's ScriptableObject settings directly from the agent, without hunting through the project window.
