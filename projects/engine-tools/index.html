Overview

Engine Tools is a set of custom Unity Editor tools built to speed up setup and iteration. I designed and built these tools to remove tedious and repetitive steps from my own workflow.

  • Dynamic Patrol System: create and edit AI patrol routes directly from the inspector.
  • Serialized Config Editor Window: edit an agent's ScriptableObject settings directly from the agent, without hunting through the project window.

Dynamic Patrol System

Manually adding patrol point transforms can quickly become messy. Keep scene hierarchy clean by dynamically adding patrol points via the inspector. Patrol point lists can then be saved or loaded as a preset, further increasing iteration speed.

Comparison

Patrol routes are traditionally built by scattering empty GameObjects through the scene hierarchy. The custom inspector replaces that with a single list on the agent, so routes stay organized and each point can be added and moved directly in the scene view.

Technical breakdown

Dynamic Patrol System

A custom inspector on the AI agent stores every patrol point in one list. Points are edited in the Scene view with position handles, drawn as labeled gizmos with connecting lines, and every change is recorded for undo. When the agent is moved in the editor, the same offset is applied to all of its points so the route travels with it.

Routes can be saved as ScriptableObject presets. Points are stored relative to the agent when saved and converted back to world positions when loaded, so a preset works wherever the agent is placed. 

// Save each point relative to the agent
        Vector3 localPos = m_Agent.transform.InverseTransformPoint(point.Position);

Serialized Config Editor Window

The editor window wraps the agent's ScriptableObject in a SerializedObject and draws every visible property automatically, so new config fields show up without any extra editor code. It listens for selection changes and re-links to whichever agent is selected, which avoids the reference being lost when switching between configs.

SerializedProperty property = _so.GetIterator();
        if (property.NextVisible(true))
        {
            do { EditorGUILayout.PropertyField(property, true); }
            while (property.NextVisible(false));
        }
Learning outcomes
  • Unity Editor scripting: custom inspectors, Scene view handles, and editor windows.
  • Working with serialization: using SerializedObject and SerializedProperty so the tools handle undo and saving correctly.
  • World vs. local space: keeping routes attached to a moving agent and making presets reusable.
  • Data-driven AI setup: storing patrol routes and agent configs as ScriptableObjects.
  • Tool design: building small tools that remove repetitive steps and make iteration faster.
